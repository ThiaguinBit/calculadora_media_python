# Sistema de Notas do Aluno 
calcular a media dos alunos

## tecnologia ultilizada
foi ultilizada a ferramenta python

## como instalar e executar 
abra o VScode instale o **PYTHON** crie uma pasta (exemplo: botao direito do mouse nova pasta de um nome para pasta) crie um novo arquivo **app.py** depois que o codigo estiver pronto revise se esta tudo certo va nos 3 pontinhos no canto esquerdo superior aperte e va na aba executar la tera uma opção (iniciar depuração) aperte e o codigo ira funcionar.
